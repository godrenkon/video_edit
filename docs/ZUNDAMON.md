# Zundamon integration

## v0.1 workflow

1. 立ち絵PSDをPSDTool等で開く
2. 口閉じ / 半開き / 口開き / 瞬きの透過PNGを書き出す
3. Suiram Video Editのメディア欄へ読み込む
4. VOICEVOXで作成した音声も読み込む
5. 「ずんだもん自動化」で各PNGと音声を選択
6. 自動口パクを生成

音声はAudioContextでデコードし、約45msごとのRMSを測定して3段階の口状態へ変換する。

## 次段階

PNGを書き出す作業自体を廃止し、坂本アヒル式等のPSD/ZIPを直接読み込んでレイヤーを選べるようにする。

予定:

- ZIP/PSD直接読み込み
- PSDレイヤーグループの解析
- 口 / 目 / 眉 / 腕 / 表情のプリセット保存
- VOICEVOXタイミング情報の利用
- 母音ベースの「あ・い・う・え・お」口パク
- セリフ単位の表情切り替え
- 字幕同期
- 複数ナレーションの一括生成

重要: 立ち絵素材本体はリポジトリへ同梱しない。ユーザーが自分で取得した素材をブラウザへ読み込ませる。
