# Feature Target

一般的な高機能動画編集ソフトで期待される機能を、実装漏れ防止のために分類したチェックリスト。

## Project / Media

- project create/open/duplicate/delete
- autosave / recovery
- folders / bins / tags / search
- relink missing media
- proxy media
- thumbnails / waveform cache
- image sequences

## Timeline

- unlimited tracks
- video / audio / image / text / generator clips
- trim / ripple / roll / slip / slide
- split / join
- snapping
- nested / compound sequences
- markers
- track lock / mute / solo / visibility
- keyframes

## Video

- transform / crop / opacity
- speed / reverse
- stabilization
- transitions
- masks
- chroma key
- blend modes
- color correction / grading
- LUT
- blur / sharpen / glow / shadow

## Text / Graphics

- text layers
- subtitle track
- SRT / VTT import/export
- shapes
- stroke / shadow / background
- templates
- motion graphics presets

## Audio

- waveform
- gain / pan
- fades
- mixer
- EQ / compressor / limiter
- noise reduction
- ducking
- voice enhancement
- loudness normalization

## Export

- MP4 / WebM
- H.264 / VP9 / AV1 where available
- transparent video
- audio only
- image sequence
- render presets
- bitrate / resolution / fps configuration

## Zundamon

- PSD/ZIP character preset
- mouth / eye / eyebrow / arm layer switching
- lip sync
- blink
- body motion
- expression presets
- VOICEVOX text/timing integration
- subtitle synchronization
